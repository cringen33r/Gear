# grid-template: subgrid
```css
.card {
	display: grid;
	grid-row: span 3;
	grid-template-rows: subgrid;
}
```
Вложенный grid использует сетку родительского. То есть его элементы выравниваются по строкам (в данном случае) родительского, что позволяет выравнивать элементы дочерних контейнеров так, будто они прямые потомки грида родительского
# repeat(auto-fill/auto-fit, \<value\>)
Повторение n раз.
auto-fill заполняет оптимально (если задан макс размер то мин объектов, если мин, то макс объектов), причём без схлопывания (в конце пустые столбцы). auto-fit схлопывает
# grid-auto-flow
Просто указание в какую сторону класть автопозиционируемые итемы.
`row/column dense` указывает, что пробелы можно заполнять более поздними подходящими итемами => может нарушать порядок
# minmax(min, max)
Просто задание сразу минимума и максимума (использовать нужно)
# Intrinsic Size
Размер без учёта внешних условий. Применим лишь для строчных элементов, как и значения, которые от него зависят.
