## `auto` в CSS — сухая выжимка

### `width: auto`

- Для блочного элемента по умолчанию.
    
- Занимает всё доступное горизонтальное пространство.
    
- Учитывает `margin`, `padding`, `border`.
    
- Не эквивалентен `width: 100%`: `100%` задаёт ширину относительно родителя, после чего `padding`/`border` могут увеличить итоговый размер.
    
- Для блочного элемента `width: auto` обычно означает «растянуться до доступного места».
    

### `height: auto`

- Значение по умолчанию.
    
- Высота определяется содержимым.
    
- Не означает `height: 100%`.
    
- Для заполнения высоты родителя обычно используются `height: 100%` при заданной высоте родителя или flex/grid-растягивание.
    

### `margin: auto`

- В обычном блочном потоке:
    
    - `margin-left: auto; margin-right: auto` → горизонтальное центрирование элемента с заданной шириной.
        
- `auto` распределяет доступное свободное пространство.
    
- Если свободного пространства нет, `auto` фактически становится `0`.
    

### `margin: auto` + absolute

Для центрирования абсолютно позиционированного элемента:

```css
.element {
    position: absolute;
    inset: 0;
    width: 200px;
    height: 100px;
    margin: auto;
}
```

Условия:

- задана `width`;
    
- задана `height`;
    
- элемент `position: absolute`;
    
- противоположные offsets (`left/right`, `top/bottom`) заданы.
    

### `margin: auto` + Flexbox

В flex-контейнере `auto` поглощает свободное пространство.

```css
.item {
    margin-left: auto;
}
```

→ элемент максимально смещается вправо.

```css
.item {
    margin-top: auto;
}
```

→ элемент максимально смещается вниз.

```css
.item {
    margin: auto;
}
```

→ центрирование по обеим осям.

Для RTL предпочтительнее:

```css
margin-inline-start: auto;
```

### `flex: auto`

Эквивалент:

```css
flex: 1 1 auto;
```

То есть:

```css
flex-grow: 1;
flex-shrink: 1;
flex-basis: auto;
```

Правила:

- исходный размер берётся из `width`/`height`;
    
- элемент может увеличиваться, занимая свободное место;
    
- элемент может уменьшаться при нехватке места.
    

### Grid: `auto`

```css
grid-template-columns: auto 1fr 1fr;
```

`auto` для трека:

- размер определяется содержимым;
    
- `1fr` получает оставшееся пространство.
    

### Grid + `margin: auto`

```css
.item {
    margin-left: auto;
}
```

- элемент прижимается вправо;
    
- ширина может определяться содержимым.
    

### `overflow: auto`

```css
overflow: auto;
```

- содержимое помещается → прокрутки нет;
    
- содержимое не помещается → появляется прокрутка;
    
- в отличие от `scroll`, не требует постоянной полосы прокрутки.
    

### `top/right/bottom/left: auto`

`auto` означает отсутствие явно заданного offset и возвращает позиционирование к естественному алгоритму размещения.

```css
.item {
    left: 100px;
}

@media (...) {
    .item {
        left: auto;
    }
}
```

`left: auto` ≠ `left: 0`.

Для абсолютно позиционированного элемента:

- `left: auto` → не прижимает элемент к левому краю;
    
- `left: 0` → явно прижимает к левому краю.
    

### Главное правило

`auto` не имеет единого значения. Его смысл определяется конкретным CSS-свойством:

```text
width: auto          → доступная ширина
height: auto         → размер по содержимому
margin: auto         → распределение свободного пространства
flex: auto            → 1 1 auto
grid: auto            → размер по содержимому/алгоритму grid
overflow: auto        → прокрутка только при необходимости
position offsets:auto → естественное позиционирование
```
