## Определение

**Бинарное дерево поиска (BST)** — двоичное дерево, для каждого узла которого:

- все ключи в **левом** поддереве **строго меньше** ключа узла;
- все ключи в **правом** поддереве **строго больше**;
- оба поддерева тоже являются BST.

Ключевое следствие: **симметричный обход (in-order) выдаёт ключи в отсортированном порядке**.

## Ограничения и требования

1. Ключи должны быть **сравнимы** — определён линейный порядок (`<`). Для составных ключей нужен компаратор.
2. Классический BST **не хранит дубликаты**; их обрабатывают отдельно (счётчик в узле или соглашение «равные идут вправо»).
3. **Сложность зависит от высоты дерева.** Все операции — O(h). У сбалансированного дерева h = O(log n), у вырожденного — h = n.
4. **Вставка отсортированных данных вырождает дерево в связный список** — все операции деградируют до O(n). Это главная практическая проблема.

## Операции

**Поиск** — сравниваем с корнем, идём влево или вправо. O(h).

```js
function search(node, key) {
  while (node) {
    if (key === node.key) return node;
    node = key < node.key ? node.left : node.right;
  }
  return null;
}
```

**Вставка** — спускаемся как при поиске, вставляем в найденный пустой слот. O(h).

**Удаление** — три случая:
- лист: просто удаляем;
- один потомок: заменяем узел потомком;
- два потомка: заменяем узел его **предшественником** (максимум левого поддерева) или **преемником** (минимум правого), затем рекурсивно удаляем этот узел, у которого гарантированно ≤ 1 потомка.

**Минимум/максимум** — крайний левый / крайний правый узел, O(h).

**Обходы:**
- *in-order* (лево → узел → право) — отсортированная последовательность;
- *pre-order* (узел → лево → право) — сериализация, копирование дерева;
- *post-order* (лево → право → узел) — освобождение памяти, вычисление размеров;
- *level-order* (BFS) — по уровням, через очередь.

**Диапазонный запрос** (все ключи в [a, b]) — O(h + k), где k — размер ответа. Это то, чего **не умеет хеш-таблица**.

**Предшественник/преемник**, **k-й по порядку** (если хранить размеры поддеревьев) — O(h).

## В JavaScript

Встроенного BST в стандартной библиотеке нет: `Map` и `Set` — хеш-таблицы (хотя порядок вставки они сохраняют, порядок **по ключу** — нет). Дерево реализуют вручную или берут библиотеку.
