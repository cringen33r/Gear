## O(1) — константа

```js
function first(arr) {
  return arr[0];        // одна операция независимо от длины
}
```

Доступ по индексу в массиве, вставка/чтение в хеш-таблице (в среднем), `push`/`pop` в конец массива.

## O(log n) — логарифм

Признак: **на каждом шаге размер задачи делится на константу** (обычно пополам).

```js
function binarySearch(sorted, target) {
  let lo = 0, hi = sorted.length - 1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    if (sorted[mid] === target) return mid;
    if (sorted[mid] < target) lo = mid + 1;
    else hi = mid - 1;
  }
  return -1;
}
```

Из n элементов после k делений остаётся n/2^k; поиск заканчивается при n/2^k = 1, откуда k = log₂n. Для n = 1 000 000 это ~20 итераций.

## O(n) — линейно

```js
function sum(arr) {
  let s = 0;
  for (let i = 0; i < arr.length; i++) s += arr[i];  // n итераций
  return s;
}
```

Сюда же: `map`, `filter`, `reduce`, `indexOf`, один проход по строке. Два последовательных цикла — это `2n`, то есть по-прежнему O(n).

## O(n log n) — «хорошая» сортировка

Признак: либо `n` независимых операций по `log n` каждая, либо схема «разделяй и властвуй», где на каждом из log n уровней выполняется O(n) работы.

```js
function mergeSort(arr) {
  if (arr.length <= 1) return arr;
  const mid = arr.length >> 1;
  const left = mergeSort(arr.slice(0, mid));   // T(n/2)
  const right = mergeSort(arr.slice(mid));     // T(n/2)
  return merge(left, right);                   // O(n)
}
// T(n) = 2T(n/2) + O(n) → O(n log n)
```

Второй типичный пример:

```js
for (const x of arr) {          // n раз
  const i = binarySearch(sorted, x);  // log n
}
```

## O(n²) — квадрат

Признак: вложенный цикл по тем же данным.

```js
function hasDuplicateSlow(arr) {
  for (let i = 0; i < arr.length; i++)
    for (let j = i + 1; j < arr.length; j++)
      if (arr[i] === arr[j]) return true;
  return false;
}
// ~n²/2 сравнений → O(n²)
```

Скрытый квадрат — частая ошибка. Здесь два «линейных» на вид метода дают O(n²):

```js
const result = a.filter(x => b.includes(x)); // filter: n, includes: m → O(n·m)
```

Правильно — заранее построить `Set`:

```js
const setB = new Set(b);                     // O(m)
const result = a.filter(x => setB.has(x));   // O(n)
```

Ещё один скрытый квадрат — конкатенация строк или `array.shift()` в цикле (shift сдвигает все элементы, O(n) за вызов).

## O(2ⁿ) и O(n!)

Наивная рекурсия Фибоначчи (`fib(n-1) + fib(n-2)`) — O(2ⁿ); перебор всех перестановок — O(n!). Практически применимы только при очень малых n.
