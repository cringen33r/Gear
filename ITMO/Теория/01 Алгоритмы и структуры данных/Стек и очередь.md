## Определения

**Стек (stack)** — LIFO (Last In, First Out): добавление и удаление с одного конца. Операции: `push`, `pop`, `peek/top`, `isEmpty` — все O(1).

**Очередь (queue)** — FIFO (First In, First Out): добавление в хвост, удаление из головы. Операции: `enqueue`, `dequeue`, `front` — все O(1) при корректной реализации.

## Реализация

Стек в JS — обычный массив с `push`/`pop` (оба амортизированно O(1)).

Очередь **нельзя** наивно делать через `push`/`shift`: `shift` сдвигает все элементы, то есть O(n), и цикл обработки превращается в O(n²). Правильные варианты:

- кольцевой буфер на массиве фиксированной длины;
- связный список с указателями на голову и хвост;
- два индекса `head`/`tail` без физического удаления;
- две стопки («очередь на двух стеках») — амортизированно O(1).

```js
class Queue {
  #items = new Map(); #head = 0; #tail = 0;
  enqueue(v) { this.#items.set(this.#tail++, v); }
  dequeue() {
    if (this.#head === this.#tail) return undefined;
    const v = this.#items.get(this.#head);
    this.#items.delete(this.#head++);
    return v;
  }
  get size() { return this.#tail - this.#head; }
}
```

## Задачи для стека

- **Проверка сбалансированности скобок**: открывающую кладём в стек, закрывающую сверяем с вершиной.
- **Обратная польская запись**, вычисление выражений, парсинг.
- **История и Undo/Redo** — два стека.
- **Обход дерева/графа в глубину (DFS)** без рекурсии.
- **Кнопка «назад» в браузере**, навигационный стек в SPA.
- **Стек вызовов** в JS-движке.
- **Задача о ближайшем большем элементе** (монотонный стек) за O(n).

## Задачи для очереди

- **Обход в ширину (BFS)** и поиск кратчайшего пути в невзвешенном графе.
- **Планировщики задач**, пул воркеров, очередь сообщений (RabbitMQ, Kafka как лог).
- **Буферизация потока данных**, rate limiting.
- **Event loop в JS**: task queue и microtask queue — именно очереди FIFO.
- **Кэш LRU** — комбинация двусвязного списка (очередь по свежести) и хеш-таблицы.
