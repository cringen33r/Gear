## Определение

**Деструктуризация (destructuring assignment)** — синтаксис ES2015, позволяющий распаковывать значения из массивов и свойства из объектов в отдельные переменные, сопоставляя структуру шаблона со структурой данных.

## Деструктуризация массивов

Работает **по позиции** и применима к любому итерируемому объекту (массив, строка, Set, Map, генератор, `arguments`, NodeList).

```js
const [first, second] = [1, 2, 3];        // 1, 2
const [, , third] = [1, 2, 3];            // пропуск позиций → 3
const [head, ...tail] = [1, 2, 3, 4];     // head = 1, tail = [2, 3, 4]
const [a, b] = 'hi';                      // 'h', 'i'
const [x = 10, y = 20] = [1];             // x = 1, y = 20

// обмен значениями без временной переменной
let m = 1, n = 2;
[m, n] = [n, m];

// вложенность
const [p, [q, r]] = [1, [2, 3]];

// из Map
for (const [key, value] of map) { /* ... */ }
```

Rest-элемент `...tail` обязан быть последним; после него нельзя ставить запятую.

## Деструктуризация объектов

Работает **по имени свойства**, порядок не важен.

```js
const user = { id: 1, name: 'Alice', address: { city: 'СПб', zip: '190000' } };

const { name, id } = user;                       // порядок произвольный
const { name: userName } = user;                 // переименование → userName
const { role = 'user' } = user;                  // значение по умолчанию
const { address: { city } } = user;              // вложенная деструктуризация
const { name: n2 = 'Аноним' } = user;            // переименование + дефолт
const { id: userId, ...rest } = user;            // rest = все остальные свойства

// вычисляемое имя свойства
const key = 'name';
const { [key]: value } = user;                   // value = 'Alice'
```

**Важно про присваивание без объявления** — нужны скобки, иначе `{` воспринимается как начало блока:

```js
let title;
({ title } = { title: 'Hi' });   // скобки обязательны
```

## Значения по умолчанию

Подставляются **только если значение строго равно `undefined`**. `null`, `0`, `''`, `false` дефолт не активируют:

```js
const { a = 5 } = { a: null };       // a === null, НЕ 5
const { b = 5 } = { b: undefined };  // b === 5
const { c = 5 } = {};                // c === 5
const [d = 1] = [undefined];         // d === 1
```

Дефолт вычисляется **лениво** — только при необходимости, и может ссылаться на ранее объявленные переменные:

```js
const { width, height = width * 2 } = { width: 10 };  // height = 20
const { data = expensiveDefault() } = props;          // функция вызовется только если data === undefined
```

## Деструктуризация параметров функции

Один из самых частых случаев применения — именованные аргументы:

```js
function createUser({ name, age = 18, role = 'user' } = {}) {
  return { name, age, role };
}
createUser({ name: 'Bob' });
createUser();                 // работает благодаря `= {}`
```

Без `= {}` вызов без аргументов даст `TypeError: Cannot destructure property of undefined`.

Практические примеры:

```js
// React
function Card({ title, children, onClick = () => {} }) { /* ... */ }

// Node.js / Express
app.get('/users/:id', ({ params: { id }, query: { page = 1 } }, res) => { /* ... */ });

// колбэки
elements.map(({ id, label }) => `${id}: ${label}`);
promises.then(([users, posts]) => { /* ... */ });
```

## Обмен и возврат нескольких значений

Функция может «вернуть несколько значений» через массив или объект:

```js
function useCounter() {
  let count = 0;
  return [() => count, () => ++count];   // как useState в React
}
const [get, inc] = useCounter();

function parse(str) { return { ok: true, value: Number(str) }; }
const { ok, value } = parse('42');
```

Объект предпочтительнее, когда значений много или порядок неочевиден — имена самодокументируют код и позволяют брать только нужное.

## Особенности и подводные камни

**Деструктуризация `null`/`undefined` бросает ошибку:**

```js
const { a } = null;   // TypeError
const { a } = {};     // ok, a === undefined
```

Защита: `const { a } = obj ?? {}` или дефолт параметра.

**Копирование поверхностное.** `const { address } = user` даёт ссылку на тот же вложенный объект; изменение `address.city` изменит и `user.address.city`.

**Вложенная деструктуризация не создаёт промежуточную переменную:**

```js
const { address: { city } } = user;
console.log(address); // ReferenceError — переменной address нет
```

**Rest в объектах** — способ «выбросить» свойство:

```js
const { password, ...safeUser } = user;   // safeUser без пароля
```

**Деструктуризация в циклах:**

```js
for (const { id, name } of users) console.log(id, name);
for (const [i, v] of arr.entries()) console.log(i, v);
```

## Связь со spread-синтаксисом

Деструктуризация «разбирает», spread «собирает»:

```js
const merged = { ...defaults, ...options };    // объединение, правое побеждает
const copy = [...arr];                          // поверхностная копия
const withId = { ...user, id: 42 };             // иммутабельное обновление
fn(...args);                                    // передача массива как аргументов
```

Оба механизма делают **поверхностную** копию — вложенные объекты остаются общими. Для глубокого копирования — `structuredClone(obj)`.
