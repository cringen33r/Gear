## Определение

**Замыкание (closure)** — функция вместе с лексическим окружением, в котором она была создана. Функция «помнит» переменные внешней области и имеет к ним доступ даже после того, как внешняя функция завершила выполнение.

```js
function makeCounter() {
  let count = 0;                 // локальная переменная makeCounter
  return function () {           // замыкание над count
    return ++count;
  };
}

const inc = makeCounter();
inc(); // 1
inc(); // 2  — count жив, хотя makeCounter давно завершилась
```

## Как возникает

Замыкания в JS создаются **автоматически при создании каждой функции**: функция получает внутреннюю ссылку `[[Environment]]` на окружение, в котором была определена. Пока жива функция — жива и цепочка окружений, на которую она ссылается, а значит, соответствующие переменные не могут быть собраны сборщиком мусора.

Важный нюанс: замыкание захватывает **переменные, а не их значения на момент создания**. Поэтому все функции, созданные в одной области, разделяют одни и те же переменные:

```js
function make() {
  let x = 1;
  return [() => x, (v) => { x = v; }];
}
const [get, set] = make();
set(42);
get(); // 42 — одно общее связывание
```

Современные движки оптимизируют захват: в контексте замыкания сохраняются только реально используемые переменные (хотя при наличии `eval` или отладчика оптимизация отключается).

## Практическое применение

**Приватное состояние (модульный паттерн):**

```js
const bank = (() => {
  let balance = 0;                       // недоступно снаружи
  return {
    deposit: (v) => (balance += v),
    getBalance: () => balance,
  };
})();
```

**Фабрики функций и каррирование:**

```js
const multiply = (a) => (b) => a * b;
const double = multiply(2);
```

**Мемоизация:**

```js
function memoize(fn) {
  const cache = new Map();
  return (...args) => {
    const key = JSON.stringify(args);
    if (!cache.has(key)) cache.set(key, fn(...args));
    return cache.get(key);
  };
}
```

**Debounce / throttle:**

```js
function debounce(fn, ms) {
  let timer;                                // состояние в замыкании
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), ms);
  };
}
```

**React-хуки** целиком построены на замыканиях: `useState`, `useEffect` и колбэки захватывают значения конкретного рендера — отсюда классическая проблема «stale closure», решаемая корректным массивом зависимостей или функциональной формой `setState(prev => ...)`.
