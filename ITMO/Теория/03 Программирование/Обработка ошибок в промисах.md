## Обработка ошибок

**Правило 1. Всегда завершайте цепочку `.catch()`.** Необработанное отклонение вызывает событие `unhandledrejection`; в Node.js по умолчанию это **завершает процесс**.

```js
window.addEventListener('unhandledrejection', (e) => {
  logToMonitoring(e.reason);
  e.preventDefault();
});
```

**Правило 2. Понимайте позицию `.catch()`.** Он ловит ошибки только из **предшествующих** звеньев. Ошибка в звене после `.catch()` останется необработанной.

```js
p.then(step1).catch(handle).then(step2);   // ошибка step2 не поймана
p.then(step1).then(step2).catch(handle);   // корректно
```

**Правило 3. Второй аргумент `.then` и `.catch` — разные вещи.**

```js
p.then(onOk, onErr);        // onErr НЕ поймает ошибку, брошенную внутри onOk
p.then(onOk).catch(onErr);  // поймает и ошибку промиса, и ошибку onOk
```

**Правило 4. Восстановление после ошибки.** `.catch()`, вернувший значение, «гасит» ошибку и цепочка продолжается в состоянии fulfilled:

```js
fetchUser()
  .catch(() => DEFAULT_USER)   // подставили значение по умолчанию
  .then(user => render(user)); // выполнится
```

Чтобы пробросить ошибку дальше — нужно `throw` внутри `.catch`.

**Правило 5. Не «проглатывайте» ошибки.** Пустой `.catch(() => {})` скрывает баги.

**Правило 6. `fetch` отклоняется только при сетевой ошибке**, но не при HTTP-статусах 4xx/5xx — проверка `res.ok` обязательна.

**Правило 7. Бросайте `Error`, а не строки** — иначе теряется stack trace. Для доменных ошибок создавайте подклассы `Error`; для оборачивания используйте `new Error('msg', { cause: original })`.

## Типичные ошибки

**Забытый `return`** — цепочка не дождётся вложенного промиса:

```js
.then(user => { fetchOrders(user.id); })   // ← нет return, следующий then получит undefined
.then(orders => ...)
```

**Promise constructor antipattern** — оборачивать промис в новый промис вместо того, чтобы вернуть существующий:

```js
// плохо
return new Promise((res, rej) => fetchData().then(res).catch(rej));
// хорошо
return fetchData();
```

**Последовательность вместо параллельности:**

```js
const a = await fetchA(); const b = await fetchB();      // 2 сек
const [a, b] = await Promise.all([fetchA(), fetchB()]);  // 1 сек
```

**Промисы всегда асинхронны.** Даже `Promise.resolve().then(fn)` выполнит `fn` не сразу, а в очереди микрозадач (см. блок 02, вопрос 6).
