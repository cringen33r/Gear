## Назначение

**Flexbox** — модель одномерной раскладки: распределение элементов вдоль **одной оси** (строки или колонки) с гибким управлением свободным пространством, выравниванием и порядком. Он появился для замены хаков на `float`, `inline-block` и таблицах.

Задачи, которые он решает элегантно: горизонтальные меню, панели инструментов, карточки с прижатой к низу кнопкой, центрирование по обеим осям, «липкий» подвал, распределение места между колонкой фиксированной и колонкой резиновой ширины.

## Оси

- **Главная ось (main axis)** — задаётся `flex-direction`;
- **Поперечная ось (cross axis)** — перпендикулярна главной.

Почти все свойства формулируются в терминах осей, а не «горизонтали/вертикали», поэтому смена `flex-direction` автоматически меняет смысл выравниваний. Это же делает Flexbox дружественным к языкам с письмом справа налево.

## Свойства контейнера

```css
.container {
  display: flex;                    /* или inline-flex */
  flex-direction: row;              /* row | row-reverse | column | column-reverse */
  flex-wrap: nowrap;                /* nowrap | wrap | wrap-reverse */
  flex-flow: row wrap;              /* сокращение для двух предыдущих */

  justify-content: flex-start;      /* вдоль ГЛАВНОЙ оси:
                                       flex-start | flex-end | center |
                                       space-between | space-around | space-evenly */
  align-items: stretch;             /* вдоль ПОПЕРЕЧНОЙ оси для каждой строки:
                                       stretch | flex-start | flex-end | center | baseline */
  align-content: stretch;           /* распределение СТРОК при wrap (нужно несколько строк) */

  gap: 16px;                        /* промежутки; row-gap / column-gap */
}
```

## Свойства элементов

```css
.item {
  flex-grow: 0;        /* доля СВОБОДНОГО места, которую заберёт элемент */
  flex-shrink: 1;      /* коэффициент сжатия при нехватке места */
  flex-basis: auto;    /* базовый размер по главной оси до распределения */
  flex: 0 1 auto;      /* сокращение: grow shrink basis */

  align-self: auto;    /* переопределяет align-items для одного элемента */
  order: 0;            /* визуальный порядок; НЕ меняет порядок в DOM */
}
```

Популярные сокращения:

- `flex: 1` = `1 1 0%` — все элементы получают **равные** размеры независимо от содержимого;
- `flex: auto` = `1 1 auto` — растут, но с учётом размера содержимого;
- `flex: none` = `0 0 auto` — фиксированный размер, не растёт и не сжимается;
- `flex: 0 0 200px` — ровно 200 px.

## Центрирование

```css
.center { display: flex; justify-content: center; align-items: center; }
/* или, короче, для одного элемента: */
.center { display: grid; place-items: center; }
```

Также работает `margin: auto` у элемента внутри flex-контейнера — он поглощает свободное место с обеих сторон.

## Flexbox или Grid

| Признак | Flexbox | Grid |
|---|---|---|
| Измерения | одно (строка **или** колонка) | два (строки **и** колонки) |
| Отправная точка | от содержимого | от макета |
| Управление | элементы распределяют пространство | контейнер задаёт сетку |
| Перекрытие элементов | нет | да |
| Типичные задачи | панель, меню, группа кнопок, карточка | страница, галерея, дашборд, форма в две колонки |

Их не противопоставляют: макет страницы делают на Grid, а внутренности отдельных блоков — на Flexbox.

Полезная идиома «адаптивная сетка без медиа-запросов» (Grid):

```css
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 16px;
}
```

## Поддержка и производительность

Flexbox поддерживается всеми современными браузерами. Он считается дешёвой раскладкой, но глубоко вложенные flex-контейнеры с `wrap` могут потребовать нескольких проходов layout — на очень больших списках стоит измерять и рассматривать виртуализацию.
