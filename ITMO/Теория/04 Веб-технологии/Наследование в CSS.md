## Наследование

Часть свойств автоматически передаётся от родителя к потомкам:

**Наследуются:** `color`, `font-*`, `line-height`, `letter-spacing`, `text-align`, `text-indent`, `text-transform`, `white-space`, `visibility`, `cursor`, `list-style`, `direction`, пользовательские свойства (`--*`).

**Не наследуются:** `margin`, `padding`, `border`, `width`, `height`, `background`, `display`, `position`, `float`, `overflow`, `z-index`.

Логика проста: типографика наследуется (иначе пришлось бы задавать шрифт каждому элементу), геометрия — нет.

Управление наследованием:

- `inherit` — принудительно взять значение родителя;
- `initial` — значение по спецификации (для `color` это чёрный, не «как у родителя»);
- `unset` — `inherit` для наследуемых свойств, `initial` для остальных;
- `revert` — вернуть значение предыдущего происхождения (обычно к стилю браузера);
- `all: unset` — сбросить всё сразу.

Важно: **наследование срабатывает только тогда, когда никакое объявление не выбрало элемент напрямую**. Оно рассматривается после каскада, поэтому даже слабый селектор, попавший в элемент, побеждает унаследованное значение от родителя с сильным селектором.
