## Почему длинный контент ломает layout

Это самая частая практическая проблема Flexbox, и у неё конкретная причина.

**Причина: `min-width: auto` (для колонки — `min-height: auto`).**

По спецификации у flex-элементов начальное значение `min-width` равно `auto`, что означает «не сжимать меньше **автоматического минимального размера содержимого**» (примерно `min-content` — ширина самого длинного неразрывного слова, самой широкой картинки или таблицы). Поэтому `flex-shrink` не может сжать элемент ниже этого порога — и элемент выдавливает соседей или вызывает горизонтальный скролл.

Типичные источники: длинный URL без пробелов, длинное слово, `<pre>`/`<code>`, таблица, вложенный контейнер со своим содержимым, изображение с большим натуральным размером.

**Решения:**

```css
.item {
  min-width: 0;         /* разрешить сжатие ниже min-content (для column — min-height: 0) */
  overflow: hidden;     /* альтернатива: создаёт новый контекст и отключает auto-минимум */
}
```

Плюс управление переносом текста:

```css
.text {
  min-width: 0;
  overflow-wrap: break-word;   /* переносить длинные слова */
  word-break: break-word;      /* агрессивнее */
  hyphens: auto;               /* переносы по слогам (нужен lang) */
}

.truncate {                    /* однострочное усечение с многоточием */
  min-width: 0;
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

Для изображений:

```css
img { max-width: 100%; height: auto; display: block; }
```

**Другие частые проблемы:**

- **Элементы не помещаются и не переносятся** — по умолчанию `flex-wrap: nowrap`; добавьте `wrap`.
- **`align-content` не работает** — оно действует только при наличии нескольких строк (то есть при `wrap`).
- **Все элементы одинаковой высоты, хотя не нужно** — следствие `align-items: stretch` по умолчанию; используйте `flex-start`.
- **`flex: 1` даёт равные ширины, хотя контент разный** — потому что `flex-basis: 0`; используйте `flex: auto`, если базой должен быть контент.
- **`justify-content` не действует** — вероятно, элементы уже заняли всё место (`flex-grow: 1`), свободного пространства нет.
- **Проценты в `flex-basis` в колонке** требуют определённой высоты родителя.
- **Схлопывание margin не работает** внутри flex-контейнера — это нормально, используйте `gap`.
