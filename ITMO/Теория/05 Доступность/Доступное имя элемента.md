## Доступное имя

Скринридер объявляет **роль + имя + состояние**, например: «Сохранить, кнопка» или «Показать пароль, кнопка, не нажата».

Порядок вычисления доступного имени (упрощённо):

1. `aria-labelledby` (ссылка на id элемента/элементов с текстом) — высший приоритет;
2. `aria-label` (строка);
3. нативная метка: `<label for>`, `alt` у изображения, `<caption>` у таблицы, содержимое `<legend>`;
4. текстовое содержимое элемента;
5. `title` — крайний, ненадёжный вариант.

```html
<!-- Кнопка-иконка без текста -->
<button aria-label="Закрыть диалог">
  <svg aria-hidden="true" focusable="false">…</svg>
</button>

<!-- Имя из существующего заголовка -->
<section aria-labelledby="s1"><h2 id="s1">Настройки</h2>…</section>
```

Правила:

- Декоративные иконки скрывать через `aria-hidden="true"`, чтобы скринридер не читал бессмысленный текст.
- Если у элемента есть видимый текст, `aria-label` **не должен ему противоречить** — иначе голосовое управление не найдёт элемент (WCAG 2.5.3 «Label in Name»).
- Ссылки «Подробнее», «Читать далее» вне контекста бессмысленны — скринридер умеет выводить список всех ссылок страницы. Уточняйте: `aria-label="Подробнее о тарифе Про"` или добавляйте визуально скрытый текст.

Визуально скрытый, но доступный текст:

```css
.visually-hidden {
  position: absolute;
  width: 1px; height: 1px;
  margin: -1px; padding: 0;
  overflow: hidden;
  clip-path: inset(50%);
  white-space: nowrap;
  border: 0;
}
```

Важно понимать разницу: `display: none` и `visibility: hidden` скрывают **и от скринридера**; `aria-hidden="true"` скрывает только от вспомогательных технологий, но элемент остаётся видимым и, что критично, **остаётся фокусируемым** — поэтому `aria-hidden` нельзя ставить на интерактивные элементы. Атрибут `inert` (современный) корректно исключает поддерево и из фокуса, и из дерева доступности.
