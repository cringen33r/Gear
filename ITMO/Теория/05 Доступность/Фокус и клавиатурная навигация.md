## Фокус и табуляция

**`tabindex`** управляет попаданием в порядок обхода:

- **`tabindex="0"`** — элемент попадает в естественный порядок табуляции (порядок DOM). Используется для кастомных интерактивных элементов.
- **`tabindex="-1"`** — элемент **не попадает** в табуляцию, но может получить фокус программно (`element.focus()`). Нужен для контейнеров, куда переводится фокус (модальное окно, целевая область «Перейти к содержимому», сообщение об ошибке), и для активного элемента в roving tabindex.
- **`tabindex="1"` и больше** — **антипаттерн**: ломает естественный порядок, создаёт непредсказуемый обход, тяжело поддерживать.

**Логический порядок.** Порядок табуляции определяется порядком в DOM. Визуальный порядок, изменённый через `order` во Flexbox, `grid-row/column` или `position`, **не меняет** порядок фокуса — возникает расхождение между тем, что пользователь видит, и тем, куда уходит фокус. WCAG 2.4.3 требует, чтобы порядок был осмысленным.

**Видимый индикатор фокуса** (WCAG 2.4.7, 2.4.11). Удалять его нельзя:

```css
/* ❌ катастрофа для клавиатурных пользователей */
*:focus { outline: none; }

/* ✅ заметный собственный индикатор */
:focus-visible {
  outline: 3px solid #0057b8;
  outline-offset: 2px;
  border-radius: 2px;
}
:focus:not(:focus-visible) { outline: none; }  /* не показывать при клике мышью */
```

`:focus-visible` — браузер сам решает, показывать ли кольцо (показывает при клавиатуре, скрывает при мыши). Индикатор должен иметь контраст не менее 3:1 с фоном и быть достаточной толщины.

**Управление фокусом при изменениях интерфейса:**

- **Открытие модального окна** — фокус переводится внутрь (на первый интерактивный элемент или на заголовок с `tabindex="-1"`); фокус **запирается** внутри (focus trap); по `Escape` окно закрывается и фокус **возвращается на элемент, который его открыл**; остальная часть страницы скрывается от скринридера (`inert` у фонового контейнера).
- **Удаление элемента, на котором был фокус** — фокус нужно перевести на осмысленное место (соседний элемент, заголовок списка), иначе он «упадёт» на `<body>` и пользователь потеряет позицию.
- **Навигация в SPA** — после смены маршрута фокус переводится на заголовок новой страницы, иначе скринридер продолжит читать со старого места и не сообщит о переходе.
- **Ссылка «Перейти к основному содержимому»** — первая в табуляции, визуально скрыта до фокуса; позволяет пропустить длинную навигацию.

```html
<a class="skip-link" href="#main">Перейти к содержимому</a>
...
<main id="main" tabindex="-1">…</main>
```

```css
.skip-link {
  position: absolute; left: -9999px;
}
.skip-link:focus { left: 8px; top: 8px; z-index: 100; }
```

Элемент `<dialog>` с `showModal()` реализует запирание фокуса, `Escape` и inert-фон нативно — это лучший выбор для модальных окон.

## Клавиатурные соглашения

Пользователи ожидают стандартного поведения (ARIA APG):

| Компонент | Клавиши |
|---|---|
| Кнопка | `Enter`, `Space` |
| Ссылка | `Enter` |
| Чекбокс | `Space` |
| Радиогруппа | `Tab` — в группу, **стрелки** — между вариантами |
| Табы | `Tab` — на активную вкладку, стрелки — переключение, `Home`/`End` |
| Меню | стрелки, `Home`/`End`, `Escape` — закрыть, буква — переход к пункту |
| Комбобокс | стрелки — по списку, `Enter` — выбор, `Escape` — закрыть |
| Модальное окно | `Escape` — закрыть, `Tab` — по кругу внутри |
| Слайдер | стрелки — шаг, `PageUp/PageDown` — крупный шаг, `Home`/`End` |
| Дерево | стрелки вверх/вниз — по узлам, вправо/влево — раскрыть/свернуть |

**Roving tabindex** — паттерн для составных виджетов (табы, тулбар, список): в группе только **один** элемент имеет `tabindex="0"`, остальные `tabindex="-1"`; стрелки перемещают фокус и переносят «нулевой» tabindex. Так `Tab` не заставляет пользователя проходить через все 20 вкладок.

**Никаких клавиатурных ловушек** (WCAG 2.1.2): из любого места должна быть возможность выйти клавиатурой.
