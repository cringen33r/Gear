# Цели
Разделение на узлы преследует следующие цели:
1. Контроль доступа к чувствительным областям памяти
2. Оптимизация векторного поиска
3. Оптимизация размеров постоянной памяти в контексте
4. Соблюдение архитектурного подхода к формированию личности через логически связную систему фактов
5. Упрощение описания связей между структурными единицами личности
6. Умное подключение релевантных фактов
