Три части:
1. Роуты - определение компонента который подгружается при переходе
2. Аутлеты - плейсхолдеры куда вставка идет
3. Ссылки - ну ссылки это ссылки

Через `:` указываются параметры при переходе к компоненту с динамическим содержимым
Через `**` указываются любой путь. Указанный в конце работает как дефолт путь (например для ошибки 404).
Проверка сверху вниз, более конкретные писать выше а более общие ниже

# Параметры
По умолчанию подгружаются компоненты путей *срочно*, то есть в начальном бандле.
Можно указать ленивую загрузку (подгружается при непосредственном переходе)

```ts
{
	path: '', 
	loadComponent: () => import('./components/home/home-page')
	.then(m => m.HomePage)
}
```

`redirectTo: '/path'` - перенаправление
`title`

Тайтл можно вычислять динамически
```ts
const titleResolver: ResolveFn<string> = (route) => route.queryParams['id'];
{
	path: '',
	title: titleResolver
}
```
