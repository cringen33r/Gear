# MDN (общее)

Используются для трёх целей:
1. Управление сессиями. Базовый сценарий - после входа сервер присылает куку с ID сессии, который потом клиент отсылает при каждом запросе ресурса
2. Сохранение предпочтений
3. Отслеживание поведения

Куки имеет ограниченный размер (около 4 кб) и отсылаются с каждым запросом, потому не подходят для хранения всех данных. Аналоги: Web Storage API и  IndexedDB API

Установка через заголовки `Set-Cookie: <cookie-name>=<cookie-value`. Отсылаются потом при каждом запросе в `Cookie: 1=1;2=2;...`

Куки бывают двух видов: долговременные (со сроком годности) и сессионые

Срок годности задаётся через атрибуты `Expires` и `max-age` 
`Set-Cookie: id=a3fWa; Expires=Thu, 31 Oct 2021 07:28:00 GMT;`
`Set-Cookie: id=a3fWa; Max-Age=2592000

В JS доступ через `document.cookie`


## Безопасность

Всегда стоит использовать атрибуты `Secure` и `HttpOnly`
`Set-Cookie: id=a3fWa; Expires=Thu, 21 Oct 2021 07:28:00 GMT; Secure; HttpOnly`

Secure указывает, что куки передаётся только через HTTPS, а HttpOnly означает, что JS не может получить доступ к кукам.


`Domain` и `Path` заголовки определяют область видимости куков. 
Если указан `Domain` то куки доступны на нём и на поддоменах
Если не указан, то только на домене откуда отправлены.
Сервер может в домен задать либо свой либо родительский домен

`Path` определяет путь, который должен присутствовать в запрошенном URL чтобы куки прилетели

`SameSite` определяет политику кроссовых запросов c куками третьих сторон. Три значения:
1. Strict - если должно отсылаться только при запросе с оригинального источника. Для важных вещей, например аутентификации
2. Lax - если переход на сайт с другого источника. используется для отслеживания переходных ссылок от партнёров (по умолчанию).
3. None - куки всегда отсылаются. Нужно также указать Secure 


### Куки-префиксы

Позволяет указать перед именем куки префиксы ` __Host-` или `__Secure-`. При получении таких куков браузеры проверяют наличие определённых атрибутов, иначе куки отбрасываются.

Требования `__Host-`:
1. Наличие `Secure`
2. Прислано с HTTPS
3. нет `Domain` (поскольку без указания домена правило строже и надёжнее)
4. `Path` установлен на `/`.
Таким образом кука строго ограничена доменом.

Требования `__Secure-` :
	1. Наличие `Secure`
	2. Прислано с HTTPS

> [!info]
>  User agents do not strip the prefix from the cookie before sending it in a request's Cookie header.
