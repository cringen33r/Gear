# MDN (общее)
## Перенаправления и заголовок `Location`

В заголовке `Location` указывается адрес, куда должен перейти клиент.

**Виды перенаправлений**

- **Временная**
    
- **Постоянная**
    
- **Особая**
    

### Постоянные

- `301 Moved Permanently` — некоторые агенты при получении такого ответа могут иметь неопределённое поведение: заменяют метод, особенно если это не `GET` или `HEAD`.  
    Чтобы устранить неопределённость, введён `308 Permanent Redirect`, который **запрещает** смену метода.  
    Кроулеры запоминают перемену.
    

### Временные

|Код|Метод сохраняется?|Тип редиректа|Применение|
|---|---|---|---|
|`302 Found`|❓ (возможно `GET`)|Временный|Устаревший, неясное поведение|
|`303 See Other`|❌ (всегда `GET`)|Временный|После `POST`, для перенаправления на результат|
|`307 Temporary Redirect`|✅ (всегда сохраняет)|Временный|Безопасный редирект, метод сохраняется|

### Особые

- `304 Not Modified` — использовать кеш
    
- `300 Multiple Choices` — имеется несколько вариантов представления ресурса. Агент либо выбирает сам, либо пользователь выбирает вручную
    

---

## Способы перенаправления

- HTTP-ответ с заголовком `Location`
    
- Скрипт: `window.location`
    
- Мета-тег `<meta http-equiv="refresh" ...>`
    

**Порядок приоритетов:**

1. HTTP-ответ
    
2. Скрипт
    
3. Мета
    

---

## Безопасные методы

Безопасные HTTP-методы — те, что не изменяют состояние сервера:  
`GET`, `HEAD`, `OPTIONS`.  
Они также являются идемпотентными.
