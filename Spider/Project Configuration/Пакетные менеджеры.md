Пакет - файл или директория, описанный `package.json`
Модуль - файл или директория в `node_modules` который может быть загружен
# versioning
1.1.1 - major.minor.patch
`^` - любые minor и patch, но тот же major
`~` - любой patch, но те же major и minor

`dist-tags` - теги указываемые после `@`, человекочитаемая форма версии

# pnpm
`npx` - выполнение модуля без его “установки”. Полный аналог - `pnpx`

# Миграция на pnpm
1. Удалить `node_modules`
2. Добавить защиту от использования `npm`
```json
"scripts": {
  "preinstall": "npx only-allow pnpm"
}
```
3. Перенести воркспейсы из `package.json` в `pnpm-workspaces.yaml`
```yaml
packages:
  # include packages in subfolders (e.g. apps/ and packages/)
  - "apps/**"
  - 'packages/**'
  # if required, exclude some directories
  - '!**/test/**'
```
4. Выполнить `pnpm import`
5. Удалить `lock`-файл
6. Установить зависимости `pnpm i`
